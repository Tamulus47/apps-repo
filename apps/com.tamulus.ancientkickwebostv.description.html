A lightweight Kick streaming app designed specifically for LG webOS Smart TVs, fully compatible with webOS 3.4 and Chromium 38 (2016+ LG TVs).

Features

  • Top & Featured Live Streams — browse popular live broadcasts on startup.
  • Search — find any channel or creator with the on-screen remote keyboard or live search.
  • Channel Profiles & VODs — creator details, follower counts, bio, live status and all past broadcasts.
  • HLS playback — fullscreen native player with adaptive MPEG-TS streams.
  • Live rewind & DVR — press Rewind to Start (yellow key) to jump to the beginning of the broadcast, press Go to LIVE (green key) to jump back to the live edge.
  • Remote-first UI — full D-pad navigation, webOS Back key, media keys and colour shortcuts (Red = Search, Green = Live Streams, Yellow = Rewind to Start).
